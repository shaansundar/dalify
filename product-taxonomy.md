## 1. Collection Hierarchy

Dalify's catalog is organized into **4 main categories** with sub-collections. Shopify uses a flat collection model (no native nesting), so we use **navigation menus** and **collection tags** to create the browsing hierarchy.

### Top-Level Collections

| Collection | URL Slug | Sort Order | Description |
|------------|----------|------------|-------------|
| All Products | `/collections/all` | Best selling | Auto-generated by Shopify |
| Spices | `/collections/spices` | Alphabetical (A–Z) | Whole and ground spices |
| Grains | `/collections/grains` | Alphabetical (A–Z) | Rice, wheat, millets, flours |
| Pulses | `/collections/pulses` | Alphabetical (A–Z) | Dals, lentils, legumes |
| Instant Mixes | `/collections/instant-mixes` | Best selling | Ready-to-cook mixes |

## 3. Naming Conventions

### Collection titles
- Use **Title Case** for display names: "Whole Spices", "Breakfast Mixes"
- Keep names short — max 3 words where possible

### URL slugs
- All lowercase, hyphen-separated: `whole-spices`, `breakfast-mixes`
- No special characters, no underscores
- Prefer singular category root + plural sub: `/collections/spices`, `/collections/whole-spices`

### Product tags (for automated collection rules)
- All lowercase, hyphen-separated: `whole-spice`, `ground-spice`, `rice`, `dal`
- Use **singular** form for tags: `whole-spice` not `whole-spices`
- Each product gets: one category tag + one sub-category tag + optional attribute tags

### Product tag taxonomy

```
Category tags:     spice, grain, pulse, instant-mix
Sub-category tags: whole-spice, ground-spice, blended-masala, seasoning,
                   rice, millet, wheat-flour,
                   dal, whole-lentil, legume,
                   breakfast-mix, snack-mix, meal-mix
Attribute tags:    organic, premium, new-arrival, bestseller, combo-pack
Weight tags:       100g, 250g, 500g, 1kg (for variant filtering if needed)
Dietary tags:      gluten-free, vegan, high-protein
```

## 4. Collection Configuration in Shopify

### Creating automated collections

For each sub-collection, use **automated rules** instead of manual product assignment:

1. **Online Store → Products → Collections → Create collection**
2. **Collection type:** Automated
3. **Conditions:** Products must match **all** conditions:
   - `Product tag` **is equal to** `[sub-category-tag]`
4. **Sort order:** Alphabetical (A–Z) for browsable categories; Best selling for curated ones

Example for "Whole Spices":
```
Title: Whole Spices
URL: /collections/whole-spices
Type: Automated
Condition: Product tag is equal to "whole-spice"
Sort: Alphabetical (A–Z)
```

### Creating top-level parent collections

For the four main categories, use a broader condition:

Example for "Spices":
```
Title: Spices
URL: /collections/spices
Type: Automated
Condition: Product tag is equal to "spice"
Sort: Alphabetical (A–Z)
```

**Important:** Every product tagged `whole-spice` must also be tagged `spice` so it appears in both the sub-collection and the parent collection.

## 6. Collection Display Settings

| Setting | Recommendation | Where to configure |
|---------|---------------|-------------------|
| Products per page | 16 (4×4 grid on desktop, 2-column on mobile) | Theme editor → Collection page |
| Collection image | Upload a lifestyle/category hero image per collection | Each collection's admin page |
| Collection description | 2–3 sentences with primary keyword for SEO | Each collection's admin page |
| Sort default | Alphabetical for browsing; Best selling for curated | Each collection's settings |
| Enable filtering | Tags, Price, Availability | Theme editor → Collection page |
| Show product count | Yes | Theme editor → Collection page |

## 7. Product Variants Strategy

Most Dalify products will have **weight variants** rather than color/size:

| Variant Option | Values | Notes |
|---------------|--------|-------|
| Weight | 100g, 250g, 500g, 1kg | Primary variant for most products |
| Pack Size | Single, Combo (2-pack), Family Pack | For combo/bundle SKUs |

Configure in **Settings → Custom data** or directly on each product. Use Shopify's built-in variant system — no apps needed for Week 1.

## 8. Product CSV Preparation Notes

When preparing the bulk upload CSV for Day 2, use this tagging scheme:

```csv
Handle,Title,Tags,Type,Vendor
organic-turmeric-powder,"Organic Turmeric Powder","spice, ground-spice, organic, bestseller",Spice,Dalify
basmati-rice-1kg,"Premium Basmati Rice","grain, rice, premium",Grain,Dalify
toor-dal-500g,"Toor Dal","pulse, dal",Pulse,Dalify
dosa-mix,"Instant Dosa Mix","instant-mix, breakfast-mix",Instant Mix,Dalify
```

- **Handle:** lowercase, hyphenated product identifier (becomes the URL slug)
- **Tags:** comma-separated, following the tag taxonomy above
- **Type:** matches the top-level category (used for Shopify's built-in product type filter)
- **Vendor:** `Dalify` for all products
